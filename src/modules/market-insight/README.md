# market-insight

可独立移除的非 AI 市场观察模块。它读取现有行情、基本面快照、K 线、盘口、资金流、板块和用户已有的 T 计划，输出估值与资本回报、确定性指标、原始来源新闻和客观观察事件。

- “估值与资本回报”展示随行情更新的市盈率 TTM、市净率，以及最新完整财年的自由现金流、ROIC和净负债；旧版基本面快照缺少后三项时提示更新。

- 关闭构建变量 `JIANZHANG_MARKET_INSIGHT_MODULE=0` 时，不安装主进程 IPC、preload bridge、renderer chunk 或模块定时刷新。
- 桌面版第一版接入巨潮资讯公司公告、中国证监会要闻以及沪深北交易所通知公告，只保存标题、发布时间和原始链接；当前用于用户本机验证，对外分发前仍需确认各来源的展示授权。浏览器预览仍使用固定演示新闻。
- 新闻层对重点关注股票每 15 分钟查询一次；其他自选股票只在交易日北京时间 15:00 收盘后查询一次，并持久化当天查询记录，应用重启不会重复。用户手动点击“立即刷新”不受自动调度限制。
- 公司公告与交易所通知分栏展示：公司公告只显示当前股票公告，沪深北交易所的全市场通知单独显示。要闻和交易所通知默认只保留最近 7 天；用户可开启“查询近 30 天要闻及交易所通知”，设置不会立即发起请求，而是在下一次自动或手动查询时生效。公司公告不受时间范围开关影响。
- 单个来源失败时保留其他来源结果并在模块状态中显示来源错误；北交所官网启用访问限制时，公司公告仍由巨潮资讯覆盖。
- 模块数据保存在 `%APPDATA%\\见涨\\modules\\market-insight\\`，不会写入核心 `AppState` 或配置导出文件。
- 内存快照、单股票事件历史和磁盘缓存文件均有上限；过期缓存会在模块安装时清理。
- `main/events/history-replay.fixture.ts` 提供固定历史回放，重复运行会得到相同事件序列。
