# 市场洞察新闻来源接入评估

评估日期：2026-07-20

## 1. 结论

第一版默认使用官方来源：

- 巨潮资讯：按证券代码获取 A 股公司公告，保留公告 ID、标题、发布时间和原始 PDF 链接。
- 中国证监会：市场政策与监管要闻。
- 上海、深圳、北京证券交易所：市场级通知公告。

第二阶段的推荐顺序是：

1. 当前用户本机版本可先增加明确标记为“实验性”的东方财富公开搜索适配器；默认关闭，以低频率获取标题、时间、媒体名和原文链接。
2. 若后续对外发行、商业使用或需要稳定服务，再洽谈东方财富 Choice，用正式资讯接口补充个股新闻、行业新闻和市场快讯。
3. AKShare 只作为接口研究和原型验证工具，不作为 Electron 运行时依赖。
4. Tushare 只有在用户提供 Token、开通新闻权限并接受个人非商业限制时才考虑接入；它缺少原文 URL 和证券代码，不适合直接进入当前新闻模型。
5. 财联社和新浪财经在取得书面授权前不接入。两者公开快讯虽快，但授权条件、证券关联和原文链接完整度都不满足默认发行要求。

## 2. 当前模型的接入门槛

`MarketNewsItem` 要求每条数据至少具备：

- 稳定来源 ID；
- 标题；
- 明确来源；
- 可解析的发布时间；
- 可跳转的原始 HTTP/HTTPS URL；
- `stock`、`sector` 或 `market` 作用域；
- 股票级新闻必须能够说明与证券的关联依据。

默认发行版还需满足：

- 允许以当前方式获取并展示标题、时间、来源和链接；
- 能说明调用频率、限流和服务变更机制；
- 不能把关键词命中伪装成来源提供的精确证券关联；
- 单个来源失败时可以降级，且不会清空其他来源或旧缓存；
- 不抓取、缓存或再分发全文。

## 3. 候选来源对比

| 来源 | 可获得字段 | 证券关联 | 原文 URL | 稳定性与运行成本 | 授权边界 | 建议 |
| --- | --- | --- | --- | --- | --- | --- |
| 东方财富公开搜索 | 文章 ID、标题、日期、媒体名，可推导财经频道文章地址 | 以证券代码/名称作为搜索关键词，属于低置信度关联 | 有，可由文章 ID 组成 | 未公开承诺的 Web 接口，字段和鉴权方式可能变化 | 协议未对该公开接口调用作专门规定；站内内容的复制、转载、传播等使用另受知识产权条款约束 | 可做默认关闭的本地实验源 |
| 东方财富 Choice | 公司、行业、新闻、公告等正式资讯数据 | 可按正式数据字段关联 | 需以正式接口合同为准 | 商业数据产品，稳定性和服务支持优于页面接口 | 需要购买或取得相应数据许可 | 正式版首选 |
| 财联社电报 | 标题/正文片段、时间；旧版公开接口曾提供电报列表 | AKShare 当前封装未输出证券代码 | 当前封装无 URL | 公开 `nodeapi` 当前可能返回页面而非 JSON，变化明显 | 未经书面授权不得复制或使用 | 授权并获得正式接口前不接入 |
| 新浪财经直播 | ID、时间、正文、`docurl`，部分条目扩展字段含股票 | 仅部分条目带股票扩展字段，不能保证 | 原始 Feed 中部分条目有，AKShare 封装会丢失 | Feed 可访问，但未承诺稳定；解析规则依赖页面服务 | 条款明确限制未经许可的机器人抓取和传播 | 授权前不接入 |
| AKShare | 可统一访问东方财富、财联社、新浪等数据 | 取决于具体上游接口 | 部分接口没有或封装时被丢弃 | 需要 Python 运行时及较多依赖；上游变化会直接造成失效 | 项目说明数据仅供学术研究，且上游数据权利独立存在 | 研究/原型工具，不进入桌面端运行时 |
| Tushare `major_news` | 标题、内容、发布时间、来源 | 无证券代码 | 无 | 正式 Token HTTP API，技术上相对清晰；新闻接口另有权限 | 服务协议为个人、不可转让、非商业许可 | 不直接接入当前模型 |

### 3.1 2026-07-20 实测记录

以下结果只说明评估当日的技术可达性，不代表接口提供方承诺稳定服务：

| 路径 | 实测结果 |
| --- | --- |
| 巨潮 `new/data/szse_stock.json` + `new/hisAnnouncement/query` | 沪、深、北 A 股均可按代码取得公告 ID、标题、时间和 PDF 路径 |
| 北交所 `disclosureInfoController/stockInfoResult.do` | 官网自身使用的 JSONP 可返回北交所公告 ID、标题、日期和文件路径 |
| 东方财富 `search-api-web.eastmoney.com/search/jsonp` | 以 `cmsArticleWebOld` 搜索证券代码可返回文章 ID、标题、日期和媒体名，文章 ID 可组成财经频道链接 |
| 财联社 `cls.cn/nodeapi/telegraphList` | 当前请求返回普通 HTML 页面，不是 AKShare 代码所期待的 JSON |
| 新浪财经 `zhibo.sina.com.cn/api/zhibo/feed` | 当前返回直播条目 JSON，包含 ID、时间、正文、部分 `docurl`，部分条目扩展字段含股票 |
| AKShare 1.18.64 | `stock_news_em` 仍调用东方财富公开搜索；财联社和新浪封装结果会丢失原始字段 |
| Tushare `major_news` | 未使用 Token 调用；官方文档确认需单独权限，输出字段没有 URL 和证券代码 |

## 4. 逐项评估

### 4.1 东方财富

公开搜索接口最接近当前 `MarketNewsItem`：

| 当前字段 | 可映射字段 | 说明 |
| --- | --- | --- |
| `id` | `code` | 文章 ID，可作为稳定来源 ID |
| `title` | `title` | 需要移除搜索高亮 HTML |
| `source` | `mediaName` | 建议展示为 `东方财富 · 媒体名`，避免误认为全部内容由东方财富原创 |
| `publishedAt` | `date` | 解析为东八区时间后存储为 ISO 时间 |
| `url` | `https://finance.eastmoney.com/a/{code}.html` | 可跳转到文章页 |
| `scope` | `stock` | 只能标记为关键词关联，不能用于触发“新公告”事件 |

主要问题：

- 搜索证券代码只代表关键词命中，不是数据源提供的精确证券归属。
- Web 搜索接口并非公开、稳定、带 SLA 的数据 API。
- 东方财富用户服务协议和法律声明没有写“调用公开接口需要书面授权”。协议的书面许可条款针对的是站内内容的使用，以及复制、修改、转载、传播、散发等行为，不能直接推导成公开接口调用限制。
- 对当前仅在用户本机展示标题、时间、媒体名并跳转原文的方式，现有协议没有给出专门、明确的接口授权结论；因此这里将其视为内容展示范围仍需自行判断，而不是认定“接口未经授权”。

如果后续需要对外分发、商业使用、服务端集中抓取或稳定 SLA，建议使用 Choice 资讯数据。Choice 官方方案覆盖公司、行业、新闻和公告等数据，并提供量化接口与服务支持。接入前需要确认：

- 是否允许在本桌面应用内展示标题、来源、时间和深链；
- 是否允许本地缓存元数据；
- 请求频率、并发、历史回溯范围；
- 是否提供证券代码、行业代码和文章唯一 ID；
- 终端用户数量和发行方式对应的许可。

官方资料：

- [东方财富用户服务协议](https://about.eastmoney.com/home/protocol)
- [东方财富法律声明](https://about.eastmoney.com/home/legal)
- [东方财富 Choice 解决方案](https://choice.eastmoney.com/solution)
- [Choice 量化接口指南](https://choice.eastmoney.com/FileDownload/DOC/CFTG.pdf)

### 4.2 财联社

财联社电报适合补充高时效市场快讯，但当前公开路径不适合直接接入：

- AKShare 使用的 `nodeapi/telegraphList` 路径当前可能返回普通网页，而不是稳定 JSON。
- AKShare 的输出只有标题、内容、日期和时间，没有原文 URL，也没有证券代码。
- 无 URL 的条目不能满足当前“每条新闻可回到原始来源”的要求。
- 财联社版权说明要求复制、转载或使用前取得书面授权。

若后续取得正式接口，应要求至少返回：

- 电报唯一 ID、标题、发布时间和永久链接；
- 关联证券代码和关联类型；
- 内容来源是财联社原创、转载还是第三方；
- 允许的展示长度、缓存期限和终端授权范围。

官方资料：

- [财联社电报](https://www.cls.cn/telegraph)
- [财联社版权与联系方式](https://www.cls.cn/our?nav=contact)

### 4.3 新浪财经

新浪财经直播 Feed 的原始条目通常包含 ID、发布时间和正文，部分条目带 `docurl`，部分扩展字段带股票信息。它的字段完整度优于 AKShare 封装结果，但仍有三个阻碍：

- 证券关联字段不是每条都有，不能把正文关键词自动提升为精确个股新闻。
- 并非每条快讯都有可长期访问的原文链接。
- 新浪财经服务条款明确限制未经许可的自动化抓取、复制、传播和展示。

因此不能因为 Feed 当前可访问就进入默认发行版。若获得授权，应直接消费获准的原始接口，保留 `docurl` 和原始 ID，不再经过会丢字段的二次封装。

官方资料：

- [新浪版权声明](https://corp.sina.com.cn/chn/copyright.html)
- [新浪财经服务使用协议](https://finance.sina.com.cn/roll/2021-05-12/doc-ikmxzfmm2033220.shtml)

### 4.4 AKShare

AKShare 很适合确认上游接口字段和快速做数据原型，但不建议把它打包进桌面应用：

- `stock_news_em` 实质上仍调用东方财富 Web 搜索接口，不能提升上游稳定性或授权级别。
- `stock_info_global_cls` 和 `stock_info_global_sina` 会丢弃原始 ID、URL或证券关联字段，不满足当前模型。
- Electron 需要额外携带 Python 运行时，以及 pandas、requests、lxml、BeautifulSoup、curl_cffi、openpyxl 等依赖，安装体积和故障面明显增加。
- AKShare 自身说明数据接口仅供学术研究、不可用于商业用途；MIT 代码许可不等于获得各上游数据的使用权。

建议保留为开发期对照工具：用于验证字段、观察接口变化、生成测试样例，不作为生产数据链路。

官方资料：

- [AKShare 项目说明](https://github.com/akfamily/akshare)
- [AKShare 个股新闻接口](https://akshare.akfamily.xyz/data/stock/stock.html#id60)
- [AKShare 全球财经快讯接口](https://akshare.akfamily.xyz/data/stock/stock.html#id66)

### 4.5 Tushare

Tushare 的优点是有正式 Token API，`major_news` 可以按来源和时间拉取多家媒体新闻，单次最多返回 400 条。主要不匹配点是：

- 输出只有标题、内容、发布时间和来源，没有原始文章 URL；
- 没有证券代码，无法可靠生成股票级关联；
- 新闻接口需要单独权限；
- 服务协议授予的是个人、不可转让、非商业、可撤销许可，不适合未经确认就随应用分发或为多用户提供聚合结果。

如果用户已经有 Token 和对应权限，可以把它作为个人本机的市场级快讯源，但仍需要解决原文 URL 缺失问题；否则不应伪造链接或把内容当成精确个股新闻。

- [Tushare HTTP API](https://tushare.pro/document/1?doc_id=130)

## 5. 推荐的第二阶段设计

### 5.1 增加关联依据

在引入媒体新闻前，建议给 `MarketNewsItem` 增加可选字段：

```ts
relation?: {
  method: 'source-code' | 'keyword' | 'market'
  confidence: 'high' | 'low'
}
```

规则：

- 巨潮按证券代码查询：`source-code/high`。
- 东方财富按代码或名称搜索：`keyword/low`。
- 全市场政策和快讯：`market/high`。
- 只有 `category === 'announcement'` 且为 `source-code/high` 的条目才能触发“新公告”事件。

### 5.2 Provider 分层

- `official`：巨潮、证监会、交易所，默认启用。
- `licensed`：Choice 或后续取得正式授权的媒体接口，凭证由主进程安全保存。
- `experimental-local`：用户主动开启的公开 Web 接口，只在本机使用，界面持续显示实验性来源提示。
- `research-only`：AKShare 脚本和接口探针，不打包、不注册为运行时 Provider。

### 5.3 统一验收清单

任何新来源进入默认发行版前必须通过：

1. 返回稳定唯一 ID、标题、发布时间和永久原文 URL。
2. 股票级条目返回来源证券代码；关键词推断必须显式标为低置信度。
3. 明确展示、缓存、深链和发行许可。
4. 明确限流、并发、历史范围和接口变更通知。
5. 只存必要元数据，不缓存或再分发新闻全文。
6. 连续观察 30 天的字段完整率、重复率、超时率和接口变更。
7. 单源失败可降级，并在界面显示具体来源状态。

## 6. 下一步

建议先做两件事：

1. 实现一个可配置、默认关闭的 `EastmoneyStockNewsProvider`，以用户本机低频请求验证关键词关联、去重、原文跳转和失败降级；不抓取正文，也不通过服务端集中转发。
2. 若未来对外发行或需要稳定服务，再联系东方财富 Choice，索取资讯接口字段样例、授权范围和桌面终端报价。
