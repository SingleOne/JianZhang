# 多市场支持阶段 7：跨市场收益分析与归因

## 1. 阶段拆分

阶段 7 分为两个独立任务：

- 阶段 7A：持仓收益汇总、收益分类、原币/人民币并列、价格/汇率归因和完整性提示。
- 阶段 7B：TWR、XIRR、收益曲线、最大回撤和市场基准比较。

阶段 7A 使用阶段 4 的成交记录、阶段 6 的统一组合账本以及阶段 3 的人民币汇率。阶段 7B 不进入本次实现。

## 2. 阶段 7A 计算口径

### 2.1 汇总维度

- 股票：每只存在持仓或历史账本的股票独立展示。
- 市场：A 股、港股和美股分别汇总。
- 账户：现阶段全部历史数据迁入“默认账户”；真正允许同一股票分布在多个券商账户的模型留到阶段 11。
- 币种：按账本事件实际发生币种汇总 CNY、HKD 和 USD。
- 组合：汇总全部数据完整的股票。

### 2.2 收益分类

- 已实现收益：卖出收入减移动平均法分摊的证券成本，不含交易费用。
- 未实现收益：当前证券市值减剩余证券成本，不含交易费用。
- 税前分红：现金分红账本的税前金额。
- 预扣税：按账本实际预扣金额单列。
- 交易费用：成交记录的佣金、平台费、印花税和其他交易费用。
- 公司行动费用：供股、证券转换等公司行动的实际费用。
- 公司行动收益：资本返还、碎股现金、权利出售、退市结算和手工现金调整。

持仓总收益计算如下：

```text
持仓总收益
= 已实现收益
 + 未实现收益
 + 税前分红
 + 公司行动收益
 - 预扣税
 - 交易费用
 - 公司行动费用
```

送股、拆股、合股和证券代码变更只改变数量或单位成本，不直接生成收益。

### 2.3 人民币证券收益归因

人民币已实现和未实现证券收益拆分为：

```text
价格贡献 = 原币证券价差 × 历史加权购入汇率
汇率贡献 = 当前或卖出证券价值 ×（当前/卖出汇率 - 历史加权购入汇率）
```

并保持：

```text
人民币已实现证券收益 + 人民币未实现证券收益
= 证券价格贡献 + 汇率贡献
```

分红、预扣税、交易费用、公司行动费用和公司行动现金继续使用各自事件发生时记录的汇率折算，不纳入证券价格贡献或汇率贡献。

## 3. 数据完整性

以下任一情况会把对应股票标记为不完整：

- 缺少统一组合账本。
- 账本出现卖出数量超过可用持仓等数量异常。
- 账本数量与当前持仓不一致。
- 有持仓但缺少当前行情。
- 缺少当前人民币汇率。
- 任一历史成交或现金事件缺少历史汇率。

处理原则：

- 原币可确认的项目继续展示。
- 不完整项目的人民币值显示为空，不使用当前汇率回填历史记录。
- 股票、市场、账户和组合人民币合计只纳入数据完整的股票。
- 汇总结果显示已纳入数量、排除数量及具体缺失原因。
- 中国官方估算汇率可以参与计算，但必须标记为估算值。
- 当前没有完整的入金、出金和现金余额流水，因此只展示“持仓收益”，账户收益不可计算。

## 4. 阶段 7A 界面

- 主标题栏增加“收益分析”入口，分析面板按需加载。
- 顶部展示人民币收益、已实现、未实现、税前分红、费用、公司行动、价格贡献和汇率贡献。
- 支持按股票、市场、默认账户、币种和组合切换。
- 每行并列展示原币分类明细与人民币分类明细。
- 正收益显示红色、负收益显示绿色、零值使用中性色。
- 所有提示和辅助文字不低于 `12px`。

## 5. 阶段 7B 任务

阶段 7B 保留以下能力：

1. 时间加权收益率（TWR）。
2. 资金加权收益率（XIRR）。
3. 日、月、季度和年度收益曲线。
4. 最大回撤及回撤区间。
5. 与各市场基准指数进行原币和人民币口径比较。

阶段 7B 开始前必须先建立完整的外部现金流记录；没有完整出入金数据时不生成 XIRR，也不把持仓收益曲线描述为账户净值曲线。

- 已实现原币/人民币并列、收益分类以及价格/汇率贡献拆分。
