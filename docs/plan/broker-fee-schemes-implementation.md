# 费用方案与账户绑定

## 本次已实现

- A 股国家 / 交易所固定费率集中维护：经手费、证管费、过户费、印花税。统一默认值用于新建方案或恢复默认，不自动覆盖已有方案。
- 费用方案保存自身固定费率，账户可覆盖其中部分费率。优先级为账户微调、绑定方案；统一默认值仅用于初始化或显式恢复。
- 沪 A、深 A / 其他 A 股分别配置佣金报价、最低起收及包含费用。新建方案默认包含经手费、证管费、过户费，不包含印花税；沪 A 可单独取消包含过户费。
- 佣金报价是包含勾选费用的合计费率。报价不变而包含费用被微调时，净佣金部分随之改变；若需要保持净佣金费率不变，应同步调整报价。迁移保存的原取整方式标记不会冻结旧参数。
- “设置 → 交易”分别提供股票账户管理、费用方案管理两个入口，打开独立界面，各自保存对应资料。
- 股票账户管理负责账户名称、启停、删除、绑定已有方案及账户固定费率微调；切换方案时清除旧账户微调，采用新方案默认值。
- 费用方案管理负责统一默认费率及方案的新建、编辑、复制、删除和试算。编辑时显示绑定账户数量及名称；新建或复制不自动修改账户绑定，保存后由股票账户管理选择绑定。绑定中的方案不能删除，停用账户也计入绑定数量。
- 港美股账户同样绑定可复用方案，保留原有港美股费用参数和成交日期模板。
- 小数规则提供四舍五入和见分进位。见分进位仅看第三位小数，第三位非零则进一分；后面的非零位不触发进位，如 `1.23001 → 1.23`，`1.231 → 1.24`。
- 新 A 股计算器先计算未取整固定费用，再从佣金报价扣除所选包含费用，得到非负净佣金；各项独立取整后，最低起收缺口补入净佣金；最终总费用直接相加，不再二次进位。卖出才计算印花税，非零过户费最低 0.01 元，零成交额不收最低费用。
- 方案试算使用新计算器。账户选择弹窗显示绑定方案、沪深佣金参数、包含费用、有效固定费率及取整规则。
- 旧账户嵌入费率一次性转换为独立方案并绑定；净佣金按原沪深最低起收组合换算报价，已有全包报价直接保留。转换后删除旧账户 `feeSettings`，正常读取只查绑定方案，不回退读取旧账户字段。
- 暂缓交易入口接入期间，迁移方案保留一个原取整方式标记，仅供旧交易参数投影使用。这样净佣金不会被投影成全包预算先取整，避免迁移前后相差一分；独立新计算器忽略该标记。
- 统一默认值、方案库和账户绑定原子保存到 portfolio-meta；历史流水的费用、成本和批次收益不重算。未新增费用方案版本或固定费率版本快照；已有历史交易字段保留。

## 本次暂缓：各交易入口统一接入及整笔成交分摊

当前交易入口只适配新配置的数据结构，仍使用原有计算流程。新的任意包含组合、精确第三位取整和补足顺序，目前由方案试算采用，尚未在以下入口统一生效：

1. **录入交易**：根据所选账户读取绑定方案，合并账户固定费率微调，按股票的沪深市场和买卖方向调用新计算器。自动费用预览与实际保存使用同一结果，手动费用仍按用户输入保存。切换录入账户仍清空录入框。
2. **行内修改与重新估算**：默认保留历史实际费用；只有主动要求重新估算时，才使用该条流水实际所属账户当前方案，并明确更新费用和相关成本 / 收益。不会因修改方案自动遍历历史记录。
3. **五档预测**：每档预计买卖费用使用当前录入 / 预测账户的有效方案和同一计算器，使盈亏平衡价格、预计净收益、浮动收益提醒使用相同口径。跨账户批次中，费用仍以每笔实际成交所属账户计算。
4. **移动流水到账户**：选择保留费用时保留原金额；明确选择重新计费时，按目标账户当前方案计算，更新两个账户的成本与股票级批次收益。历史费用不会因为移动操作无条件重算。
5. **整笔成交先计算一次，再分摊**：一笔成交跨 T 仓、底仓或多个批次时，先按券商的一笔实际成交额计算完整费用，最低起收只应用一次，然后按各部分成交数量分摊费用。以分为单位分配，最后一份接收尾差，保证分摊总和严格等于整笔费用；不会对每个拆分部分重复收最低佣金。

例：一笔 1,300 股成交总费用 1 元，其中 1,000 股归 T 仓、300 股归底仓，分配总费用分别为 0.77 元、0.23 元；不能把两份各作为独立成交收取 1 元最低费用。实际实现需对每一费用项都保留分摊守恒，并覆盖正 T、反 T、超量关闭和跨批次分配。

这里的“整笔”指同一账户下券商的一笔成交，跨账户的不同成交不能合并成一笔收取最低佣金；跨账户批次收益只汇总各自真实流水及已经计算的费用。
