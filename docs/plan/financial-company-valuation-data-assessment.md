# 金融企业专用估值数据评估

> 评估日期：2026-09-08
>
> 对应实现：基本面自适应估值阶段 D

## 结论

当前基本面快照可以稳定提供金融企业的 PB、PE 和年度 ROE，但尚不能从现有普通财务报表字段可靠构造银行、保险、证券公司的全部专用估值指标。因此，本阶段只展示已有事实、行业专用主框架和待接入指标，不输出完整金融估值结论，也不复用普通企业 FCFF、PCF、净负债或 DCF。

## 当前可用事实

| 指标     | 当前来源                                | 用途                                   |
| -------- | --------------------------------------- | -------------------------------------- |
| PB       | 东方财富 `RPT_VALUEANALYSIS_DET`        | 银行、证券的主要估值事实；保险仅作辅助 |
| PE TTM   | 东方财富 `RPT_VALUEANALYSIS_DET`        | 信息展示，证券公司需特别注意盈利周期   |
| 加权 ROE | 东方财富 `RPT_F10_FINANCE_MAINFINADATA` | 银行、证券的主要质量事实；保险仅作辅助 |

## 尚未接入的专用指标

| 类型 | 主框架               | 必需但未接入的数据                                           |
| ---- | -------------------- | ------------------------------------------------------------ |
| 银行 | PB−ROE 与资产质量    | 净息差、不良率、拨备覆盖率、资本充足率、成本收入比           |
| 保险 | P/EV 与新业务价值    | 内含价值、新业务价值、偿付能力充足率、综合成本率、投资收益率 |
| 证券 | PB−ROE、净资本与周期 | 净资本、风险覆盖率、杠杆、经纪/投行/自营收入结构             |

## 本阶段产品行为

- 金融企业进入独立估值卡，不再展示三个普通企业现金流模型的“不适用”空面板。
- 当前 PB、ROE、PE 逐项显示角色、来源和数据日期。
- 未接入指标逐项标注“未接入”，总体结论固定为“数据不足”，可信度为“不可用”。
- 共享的历史与行业 PE/PB 卡片继续保留，PCF、普通自由现金流、ROIC 和净负债仍按既有规则显示“不适用”。
- 长期价值 AI 读取同一份 `financialValuation` 结构，不允许自行补造专用数据或改用普通企业模型。

## 后续接入门槛

任一金融子行业只有在满足以下条件后，才可以把专用框架从“数据不足”升级为可用：

1. 明确字段定义、单位、报告期和原始来源。
2. 完成全市场覆盖率与历史连续性诊断。
3. 对缺失值、口径变更和异常值保留明确状态，不以零补齐。
4. 建立独立计算模块和固定测试样例，不与普通企业 FCFF 共用公式。
5. UI 与长期价值 AI 只消费同一份结构化结果。
