# 持仓周期收益列头提示验证

## 变更范围

- 顶部三段说明移入对应列头的 tooltip：周期列说明累计范围和持仓天数，理财参考收益列说明当前参考年化与计息规则，峰值资金占用列说明资金占用口径，周期收益率列说明计算公式。
- “较参考多赚 / 少赚（人民币）”改为“收益比较”；“理财参考收益”“峰值资金占用”“周期收益率”去掉列头括号及括号内内容，单位和计算口径保留在提示中。
- 股票净收益列提示说明收益调整口径，收益比较列提示说明差额含义，完整性列提示说明数据问题标识。
- 收益计算、数值显示、正负颜色及交易记录入口沿用原有逻辑。

## 静态校验

执行 TypeScript、ESLint、变更文件 Prettier 和差异检查，并由 Luna 静态复核。此次不主动启动界面或打包。

## 人工验收

1. 从收益分析或自选股打开持仓周期收益弹窗，确认顶部三段说明已收起，表格四个列名与变更范围一致。
2. 分别悬停或用 Tab 聚焦周期、股票净收益、理财参考收益、收益比较、峰值资金占用、周期收益率、完整性列头，确认说明对应，提示不受表格滚动容器裁切，按 Esc 可关闭。
3. 在设置的“交易”中填写参考年化后重新打开弹窗，确认理财参考收益列头提示显示当前年化；未设置时显示设置入口说明。多账户表格应显示相同的全局参考年化。
4. 核对理财参考提示包含公式、首日计入与截止日不计入、同日日终净占用、清仓停止计息、历史汇率及修改年化重算的说明；峰值占用和周期收益率提示应保留成本、税费、校准、收益调整及不可计算时的说明。
5. 检查深浅主题及横向滚动，确认提示字号不低于 12px、收益和参考年化的正负颜色正常；表格收益、累计金额及交易记录入口仍可正常使用。
