# 官方来源 HTTP 403 修复验证

## 修复范围

- 财报库、基本面、公司行动、市场资讯与新闻摘要，以及 AI 官方 PDF 读取接入统一的官方来源请求层，覆盖巨潮、SEC 和港交所。
- 系统网络连接返回 HTTP 403、连接失败或缓冲式正文读取失败时，用 Node 独立连接重试一次；保留请求头、POST 参数和手动重定向选项，备用连接使用新的超时计时。调用者主动取消、HTTP 401/404/429/500、JSON 解析错误不重试。
- AI PDF 仍通过流式读取检查 32 MB 上限与重定向目标；这里只在连接失败或 HTTP 403 时重试，流式正文读取及解析错误不重试。
- SEC 的原请求头在本次无界面请求中返回 403；应用名称与版本的 `User-Agent` 配合已有联系方式 `From` 返回 200，默认请求头已据此修改。保留 `JIANZHANG_SEC_USER_AGENT` 自定义覆盖能力。SEC 访问规范参考[官方文档](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)。
- 所有 SEC 请求（包含备用连接和文档下载）共用 150 毫秒的请求启动间隔。股票代码目录在两条连接均返回 403 时改查 SEC 另一份官方 `company_tickers.json`；该目录没有交易所字段，留空而不推测。
- 巨潮共用股票目录与公司身份匹配：主站目录两条连接均返回 403 时使用官方静态站目录。财报库、公司行动和股票公告的历史查询仍返回 403 时，改用官网公告搜索，并分页按 `orgId`（缺失时按代码）筛选公司。
- 财报备用搜索增加“报告”关键词，减少无关公告和分页波动。最后实测的长安汽车 32 条财报与先前完整结果逐项比对，报告 ID 无缺失，包含 2026 年一季报与 2025 年年报。
- 查询失败沿用各服务已有的缓存保留与错误提示；不会将 403 一律描述成“访问频率受限”。
