# 财报库巨潮资讯 HTTP 403 修复验证

## 行为

- 财报库继续优先查询巨潮历史公告接口；系统连接返回 HTTP 403 时先用 Node 独立连接重试，仍被拒绝则改用巨潮官网的公告标题搜索接口。公司行动、市场公告、股票目录和 SEC 等来源的后续修复见 [官方来源 403 修复验证](official-source-403.md)。
- 备用查询读取股票目录中的公司简称，按日期范围逐页获取公告；优先按稳定的 `orgId` 校验公司身份，缺少 `orgId` 时才按股票代码校验，支持北交所换代码之前的旧公告。
- 从搜索结果识别年报、半年报、一季报和三季报，保留全文、正文、摘要、英文版和修订版。过滤审计报告、报告更正公告和业绩说明会预告等非财报公告。
- 报告 ID、官方 PDF 地址、排序、近五年筛选与已有 AI 摘要关联沿用原有逻辑。备用查询也失败时继续抛出错误，由财报服务保留已有缓存并显示更新失败原因。
- HTTP 429、500 等其他错误不触发备用查询或备用连接，避免在服务限流或异常时额外增加请求。

## 人工验收

1. 运行更新后的应用，打开 A 股“财报库”，手动刷新，确认出现定期报告列表。
2. 检查年报、半年报、一季报、三季报及摘要、修订版分类，打开报告检查官方 PDF 链接。
3. 刷新有本地缓存的股票，网络不可用时确认旧报告与 AI 摘要仍显示，并提示在线更新失败。
