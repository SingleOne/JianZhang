# 主界面收益卡片高度验证

## 布局约定

- “今日总收益”和“持仓收益”两张卡片按内容自然确定高度，保持等高并与标题区顶部对齐。
- 左侧持仓概览、涨跌幅分布或指数卡片换行时，右侧收益卡片不随标题区整体高度拉伸。
- 卡片内标题、收益金额、收益率保持紧凑的三行布局；收益汇总整体换至下一行时，继续靠右排列。

## 静态校验

检查收益区域的 Flex/Grid 对齐、百分比高度及响应式覆盖关系，并运行 TypeScript、ESLint、相关文件 Prettier 和 `git diff --check`。不启动界面，不执行 `build:unpacked`。

## 人工验收

1. 在宽窗口查看主界面，确认两张收益卡片顶部对齐、等高，三行文字间距紧凑。
2. 逐步缩窄窗口，使左侧指数卡片换至第二行，确认收益卡片维持自然高度，金额和收益率之间没有大块空白。
3. 继续缩窄至收益汇总整体换到下一行，确认两张卡片仍靠右、等高，左侧分隔线与收益区域等高。
4. 在深色、浅色主题下分别检查以上状态，以及正收益、负收益、零收益和较长金额：文字应完整可读，颜色及数字动画正常。
