# 市场资讯 AI 总结验收（18.4.0）

## 交互与数据

- 市场资讯的“要闻、公告、交易所通知”每一条都提供“AI 总结”。点击后读取官方网页或 PDF 原文，调用财报库共用的当前 AI 提供商、模型与凭证，不根据标题编造正文。
- 总结直接显示在标题下方，附模型与生成时间；生成期间显示“总结中”并禁止同条重复点击，有结果后按钮变为“重新总结”。不同资讯可以分别生成。
- 生成失败显示当前条目的错误，已有总结继续保留。重新打开页面、刷新资讯或重启应用后，从本地恢复同条原文的总结；标题、原文链接或发布时间变化时不复用旧结果。
- 仅保存总结和原文标识等元数据到 `modules/market-insight/news-summaries.json`，不保存下载的原文。市场观察缓存清理不删除总结，完整数据备份包含总结。
- 完成通知可返回该股票的市场观察页面。全市场资讯的总结按原文共享，不描述为某只股票专属公告。
- 浏览器预览明确提示需要在桌面版使用，不假装已经读取原文或调用 AI。

## 静态校验

- TypeScript、ESLint、Prettier 和生产构建。
- 市场观察模块回归测试，以及财报总结辅助函数、完成通知、备份恢复和缓存清理相关测试。
- 新增测试覆盖 HTML 与 PDF、嵌套正文提取、同条并发请求合并、多条并发保存、重启恢复、失败保留旧结果、错误 JSON、非官方来源和空正文。
- 按项目规则使用 Luna 静态复核；不主动启动界面或执行 `build:unpacked`。

本次结果：10 个测试文件、50 项测试通过；TypeScript、修改文件的 ESLint/Prettier、`npm run build` 和 Luna 静态复核均通过。未进行界面验收或实际 AI 请求。

## 人工验收

1. 在 AI 设置中配置提供商、模型和凭证，打开股票的“市场观察 → 市场资讯”。
2. 在三个分类各选一条执行“AI 总结”，检查原文入口仍可独立打开，生成状态与总结内容显示正确。
3. 检查总结中的日期、数量、计划与生效状态能在原文找到依据；公司公告与全市场通知的范围区分正确。
4. 执行“重新总结”，检查模型和时间更新；制造网络或 AI 配置错误，检查错误显示且已有总结保留。
5. 在生成期间切换股票或分类，完成后返回，检查结果仍对应原始资讯；点击完成通知可回到对应股票的市场观察。
6. 刷新资讯、重启应用或清理市场观察缓存后重新获取资讯，检查已保存总结仍可关联；备份并恢复后再次检查。
