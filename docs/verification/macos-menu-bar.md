# macOS 菜单栏行情验证

已实现原生菜单栏行情和点击展开面板。

## 运行

在 JianZhang 项目目录执行 `npm run dev`。开发命令会编译并启动 Electron；无需生成安装包。

## 使用

- 在自选列表的操作列选择“在菜单栏展示实时行情”，可以选择多只。
- 在“设置 → 系统”切换菜单栏展示内容：单股行情、所选股票今日收益合计（人民币）、仅图标。
- 单股模式默认固定显示第一只所选股票；右键菜单栏入口，在“固定显示股票”中更换。
- 单股模式支持关闭轮播，或每 5、10、15、30 秒切换一只股票。
- 轮播切换股票时使用约 280 毫秒的上移淡入淡出，按所选股票中最长内容预留宽度，报价更新不会触发切股动画。系统开启“减弱动态效果”时直接切换；关闭轮播、切换展示模式或退出时清理动画资源。
- 左键点击菜单栏入口展开面板；再次点击、点击外部、按 Esc 或点击“收起”关闭面板。
- 点击股票行展开该股详细行情，再次点击同一行收起；点击另一行时自动收起前一行，同一时间最多展开一行。展开详情中的“在主窗口查看”可打开主窗口并定位股票，底部仍可打开见涨或立即刷新行情。
- 概览与详细行情整合在同一 macOS 原生面板中，使用模糊材质、系统阴影、圆角、细分隔线和圆润按钮；展开详情不再额外绘制浮窗边框或阴影，跟随深浅主题并适配系统“降低透明度”和“增强对比度”偏好。
- 股票行内的详情复用 Windows 任务栏行情内容，包含分时走势、五档数量、持仓、T 仓和提醒；只在展开时加载分时与五档数据，切换或收起详情后清理该项数据请求的回调。关闭概览面板后清空展开状态，鼠标悬停不再打开二级浮窗。
- 行内详情按行情卡参考设计布局：标题保留名称、代码、市场和时间，大号中性价格旁排列涨跌额与涨跌幅，今日收益靠右；今开、最高、最低、换手横排，其下为带渐变填充的宽幅走势与分色五档数量，底部依次显示六列持仓及 T 仓浮动收益和收益率。窄窗口自动换行，缺少走势数据时显示 `--`。
- 菜单栏面板采用精简行情列表：左侧显示名称、代码与状态，右侧对齐价格、涨跌额与涨跌幅；每只股票不再显示今日收益、持仓收益、市值和 T 仓批次行。有提醒时显示附加行，容纳不下时自动换行。顶部今日收益合计保留，展开详情仍提供完整持仓、T 仓批次和收益数据。
- “菜单栏行情”关闭后保留图标入口，点击仍可查看所选股票。
- 右键可刷新、切换自动刷新范围、进入“仅菜单栏模式”或退出。

## 人工验收

1. 选择两只以上且名称长度不同的股票，检查固定显示、轮播顺序和时间间隔；切股应平滑上移淡入淡出，周围菜单栏项目不应左右跳动，报价刷新不应反复播放动画。切换系统“减弱动态效果”后应直接切股；取消当前固定股票后应自动回退到第一只。
2. 切换三种展示内容，检查红涨绿跌、正负号和收益合计；重启后检查设置恢复。缺少可计算数据的项目应显示 `--`。
3. 展开面板，检查每只股票只显示基本行情和提醒，已移除逐股今日收益、持仓收益、市值及 T 仓批次行；没有提醒的股票应只有一行。对照主窗口核对同一股票的数据，点击该行后可查看完整详情。
4. 检查点击外部、Esc、重复点击菜单栏入口均能收起；在展开详情中点击“在主窗口查看”可定位；关闭主窗口后仍能打开面板。
5. 启用“关闭后驻留”，关闭主窗口并等待刷新，检查菜单栏继续更新；点击 Dock 图标应恢复主窗口。“仅菜单栏模式”重启后也应保留。
6. 切换系统深浅主题、外接显示器、显示缩放和桌面空间；在其他应用全屏时展开菜单栏面板，检查定位、边界和滚动。
7. 开市时暂时断开网络，等待行情超过实时有效期，检查菜单栏与面板显示“已过期”；恢复后刷新应恢复状态。休市行情应标记“休市”，缺少行情时间应标记“时间未知”。
8. 关闭“关闭后驻留”，关闭主窗口，检查应用退出；右键“退出”也应清理菜单栏入口与面板。
9. 选择有持仓和多个 T 仓的股票，概览列表不应显示收益和批次明细，也不留空行；展开详情仍显示完整信息。行情刷新或提醒自动换行后，窗口应随内容调整高度。
10. 检查长股票名、较大价格和多条提醒：信息不被省略，窄屏时行情自动分行；窗口内容较长时可滚动，涨跌数字和收益合计保持正红负绿、零值中性，文字不小于 12px。
11. 点击股票 A 展开，点击 B 切换到 B，重复点击 B 收起；同一时间最多一行展开。鼠标悬停不弹出窗口，滚动时展开状态保持。使用 Tab、Enter 和空格完成相同操作；关闭概览再打开时全部折叠。移除正在展开的股票后详情应立即消失。
12. 检查概览与行内详情的深浅主题、背景、圆角和分隔线；详情不应有独立卡片边框或阴影。切换系统“降低透明度”和“增强对比度”，确认文本仍清晰可读，展开操作不应抢走当前股票行焦点。
13. 在短列表中反复展开与收起详情，检查面板随内容增减高度，底部不残留空白。使用多个 T 仓与提醒的长详情时，面板高度到达上限后应可滚动，底部按钮和明细不被截断。切换深浅主题、等待字体和样式载入后也应贴合内容。
14. 将页面缩放到 83%、91% 或 120% 后展开与收起详情，面板高度应按实际缩放贴合内容；恢复 100% 后同样不留底部空白。宽度变化但 CSS 高度相同时也应重新上报尺寸，不重置用户的缩放设置。

Windows 继续使用原有任务栏行情条与托盘悬停摘要；新增菜单栏偏好保存在原有设置中，旧配置自动补默认值。
