# 腾讯 K 线备用域名验收

腾讯 K 线每次先请求 `ifzq.gtimg.cn`；失败后请求 `web.ifzq.gtimg.cn`，两个节点分别最多请求一次。备用请求保留路径、参数、请求头和 12 秒超时，返回数据继续使用现有腾讯 K 线结构。

## 自动校验范围

- A 股及港股日/周/月 K：腾讯主节点 HTTP 501 后由备用节点恢复，兼容 `qfqday/qfqweek/qfqmonth` 与 `day/week/month` 字段。
- 五日线、A 股一分钟 K：腾讯主节点失败后使用备用节点；一分钟主备都失败时继续尝试新浪及已有五分钟降级链路。
- 腾讯主节点连接异常、JSON 解析失败、业务错误、空数据均触发备用节点。
- 主节点正常时不访问备用节点；上一次使用备用节点不改变下一次请求顺序。
- 两个腾讯节点都失败时保留各节点错误，历史缓存仍由现有 `KlineHub` 处理。
