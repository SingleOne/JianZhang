# 任务栏浮窗股票标题累计收益

## 行为

- Windows 股票任务栏悬浮详情的标题栏显示该股票的累计收益，直接更新数值。
- macOS 菜单栏股票标题仅在对应股票行展开时显示累计收益，使用约 320 毫秒的淡入动画；收起后隐藏，其他未展开股票不显示。累计收益标签与金额字号均为 14px。数值更新沿用滚动动画；系统开启“减弱动态效果”时直接显示。
- 数据使用与主窗口一致的 `portfolioPerformanceCache.cumulativeProfitByQuoteId`，为收益分析最近保存的人民币累计收益；有持仓时也不改用当前持仓收益。尚未生成缓存或数值为空时显示 `--`。
- 正数红色、负数绿色、零值与缺失值中性；保留正负号和人民币符号，文字不小于 12px。
- Windows“今日收益与 T 仓概览”浮窗保持原样，不新增标题累计收益。

## 静态校验与待验收

- 组件测试覆盖持仓与空仓股票的累计收益、人民币格式、正负颜色、零值与缺失值，以及 Windows 静态标题和 macOS 仅展开行显示的条件。
- 展开动画测试覆盖股票名称的位置、字号、字重过渡与四个行情数字的双向移动、快速反向操作、切换股票、动画结束清理与减弱动态效果。
- 人工待验收：在两端核对股票标题累计收益与主窗口一致；macOS 反复展开、收起和切换股票，检查仅当前展开的股票标题显示累计收益，淡入后不残留副本，收起后不占位；刷新缓存后检查数字更新动画。检查深浅主题、长股票名、较大金额及窗口缩放时文字不重叠。
- 本次不启动界面、不执行构建或打包；实际显示和动画效果仍需人工验收。
