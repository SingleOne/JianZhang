# 见涨

面向 Windows 11 的本地 A 股实时行情桌面应用。

## 功能

- 通过股票代码或中文名称搜索并添加自选股
- 批量刷新最新价、涨跌幅、今开、最高、最低和成交额
- 支持在独立排序列中拖拽或一键置顶股票、点击列头快捷排序，并可一键恢复手动顺序
- 支持自由调整表格列的位置，操作列会固定吸附在表格最右侧
- 可录入持仓数量、成本价和是否本日建仓，实时计算持仓市值、今日收益、今日收益率、持仓收益和收益率
- 在自选区域汇总展示全部持仓的今日总收益、今日收益率、持仓总收益和加权总收益率
- 点击股票行展开最近交易日的盘中分时图；主接口失败时自动切换到 5 分钟备用数据
- 分时区域展示价格折线、本日成交均价线、成交量和今日概览
- 展开区域提供分时、五日、日 K、周 K、月 K 和资金流向标签页，各周期行情仅在首次打开对应标签时按需获取
- 表格可按日期倒序显示最近 5 天的东方财富盘口异动标签，没有异动的股票保持为空
- 可手动将股票设为重点关注，持仓股票会自动加入重点关注且保持重点状态
- 在 Windows 11 任务栏直接显示多只股票的名称、实时价格和涨跌幅
- 可随时开启或关闭任务栏行情，重新开启时会自动恢复显示
- 可通过滑块自由调整任务栏行情的横向位置，避开已有任务栏内容
- 分别设置重点关注与其余股票的 3–300 秒刷新间隔，默认分别为 5 秒和 10 秒
- 支持开机自动启动、关闭窗口后驻留通知区
- 自选列表和设置保存在本机，不需要注册账号
- 支持将自选、持仓、排序、任务栏选择和应用设置导出为 JSON，也可从 JSON 配置完整恢复

## 安装与使用

1. 双击 `见涨-Setup-1.0.8-x64.exe`。如果已经安装旧版本，可选择原安装目录直接覆盖升级。
2. 选择安装目录并完成安装。
3. 在顶部搜索框输入 `600519` 或 `贵州茅台` 一类的代码/名称，选择结果后添加。
4. 点击股票行展开行情详情，默认显示分时走势，可按需切换五日、日 K、周 K、月 K 或资金流向；再次点击股票行可收起。
5. 在“操作”列点击星标可切换重点关注；有持仓的股票会自动保持重点关注，并按重点股票的刷新间隔更新。
6. 在“操作”列点击任务栏图标，该股票的名称、实时价格和涨跌幅会直接显示在 Windows 11 任务栏空白区域；再次点击可取消。
7. 在“操作”列点击持仓图标，可录入持仓数量、成本价和是否本日建仓；“本日建仓”会在次日自动失效，今日收益恢复按昨收计算。
8. 在最左侧“排序”列拖动手柄可保存手动顺序，点击图钉可将股票置顶；点击任一数据列头可临时排序，点击“恢复手动排序”返回手动顺序。
9. 点击“调整列位置”，可将列向左或向右移动一格，也可直接移到最左或最右；弹窗内的列表会在下次打开时显示最新顺序，便于连续调整同一列。操作列始终固定在最右侧。
10. 在“设置”中可分别修改重点关注和其余股票的刷新秒数，也可设置任务栏行情、开机启动和关闭后驻留行为。
11. 在“设置”的“配置管理”中可导出或导入 JSON 配置；导入会先提示确认，确认后覆盖当前全部自选和设置。

安装包未使用商业代码签名证书。Windows SmartScreen 可能显示“未知发布者”，请仅在确认安装包来自本交付目录时继续。

任务栏行情条使用透明、鼠标穿透窗口，不会拦截原任务栏的点击。使用任务栏自动隐藏时，行情条也会隐藏，避免覆盖其他应用内容。

## 数据说明

应用使用东方财富公开行情接口获取 A 股联想、批量报价、盘中分时、周期 K 线、盘口异动提示和个股资金流向。行情存在网络延迟或服务调整风险，仅供信息参考，不构成投资建议。

## 本地数据

自选股和设置保存在 Electron 的用户数据目录中，通常位于：

```text
%APPDATA%\见涨\settings.json
```

## 源码开发

需要 Node.js 20 或更高版本。

```powershell
npm install
npm run dev
npm run build
npm run package:win
```

技术栈：Electron、React、TypeScript、Vite、Lightweight Charts。
