# 见涨

面向 Windows 11 的本地 A 股实时行情桌面应用。

开发维护请从 [开发者 Wiki](docs/wiki/README.md) 开始，可按功能快速定位架构、行情、做 T、状态与 IPC 等代码。

## 功能

- 通过股票代码或中文名称搜索并添加自选股
- 提供A股分红融资回报分析：深度榜单可按净回报额、累计分红/融资、连续分红年数和透明质量评分筛选；更新变化页识别新入榜、移出、排名、分红和融资变化；可视化选股用累计融资/分红对数散点图比较股票
- 主表显示分红融资比与榜单排名，个股展开详情提供近3/5年分红、年度分红图、股权融资时间线和五项质量评分拆解
- 批量刷新最新价、涨跌幅、今开、最高、最低和成交额
- 支持在独立排序列中拖拽或一键置顶股票、点击列头快捷排序，并可一键恢复手动顺序
- 支持自由调整行情数据列的位置；设置列固定在左侧第二列，四个快捷操作以两行图标展示，删除按钮独立放在表格末列
- 可录入持仓数量、成本价（支持 4 位小数）和是否本日建仓；今日收益与今日收益率会结合当日买卖成交、交易费用、昨收和当前市值计算
- 持仓天数按 A 股实际交易日计算，周末和交易所法定休市日不计入；程序每年首次运行时自动从上交所更新当年休市日历，也可在设置中手动刷新并查看最近刷新时间
- 新增独立做T账本，逐笔记录T仓买卖和底仓增减，并汇总到统一交易记录；旧版做T历史流水会自动回填，当前T仓数量、移动加权成本、已实现收益、浮动收益及收益率自动维护
- 每个活动T批次同时提供买入、卖出两套五档计划：默认分别为 -1%～-5% 与 +1%～+5%，可修改每档目标幅度和数量，并计算扣除预计费用后的本档、累计及全仓价差收益
- 活动T批次可开启买卖十档价格提醒；达到目标价后，主表格名称旁和 Windows 任务栏行情会持续闪烁对应颜色的 T1～T5 标识，记录对应交易、手动处理或结算批次后停止提醒
- T仓清空后自动进入批次结算，可填写券商最新持仓数量和成本；填写后以持仓成本推算的做T收益为准，并保留流水收益用于对账
- 做T交易自动计算佣金、经手费、证管费、过户费和卖出印花税：深A将过户费计入最低 5 元，沪A过户费在最低 5 元外单独收取；支持在设置中调整费率，也允许逐笔覆盖实际费用
- 做T批次、全部交易流水、费用明细和最终收益永久保留在本地历史中，允许修改成本校准收益或删除历史批次（删除前需确认），并随配置一并导入导出
- AI 分析和做T参考会按股票保留最近一次结果，切换标签或重启应用后自动恢复；重新生成期间旧结果继续显示，并在结果顶部突出生成时间和快照时间
- 在自选区域汇总展示全部持仓的今日总收益、今日收益率、持仓总收益和加权总收益率，收益卡片随正负显示红色或绿色阴影
- 在“添加自选”按钮后展示可自定义选择的大盘指数最新点位和涨跌幅，并以竖线分隔；指数卡片的边条和阴影随涨跌变为红色或绿色，支持上证、深证、创业板、沪深300、科创50、中证系列及北证50等常用指数
- 点击股票行展开最近交易日的盘中分时图；主接口失败时自动切换到 5 分钟备用数据
- 分时区域固定铺满展示 09:15 集合竞价至 15:00 收盘的完整时段，价格与成交量使用上下两个独立图表且不支持缩放，并标注连续竞价范围内的最高价和最低价
- 分时价格图通过背景区分集合竞价和连续竞价，保留本日成交均价线；鼠标移到价格或成交量数据点时，分别提示对应价格或成交量与成交额
- 展开区域提供分时、五日、日 K、周 K、月 K、资金流向和板块标签页，各类行情仅在首次打开对应标签时按需获取
- “板块”标签页展示股票所属主行业板块指数的最新点位、涨跌幅、今开、最高、最低、昨收、成交额和 09:30–15:00 连续竞价走势，价格轴根据实际波动自动缩放
- 五日图固定展示最近 5 个交易日的完整范围，不支持拖动或缩放
- 日 K、周 K、月 K 会持久化缓存并在向外缩放时自动补取更早行情，始终将最新交易日固定在图表最右侧，并标注当前可见范围内的最高价与最低价
- 日 K、周 K、月 K 主图叠加本地计算的 BOLL(20,2) 上轨、中轨和下轨，图表下方显示最新或十字光标所在周期的三轨价格，并可通过持久化开关隐藏
- 鼠标移到五日或周期 K 线数据点时，今日概览会切换显示该点的开盘、收盘、最高、最低、成交量和成交额；日 K、周 K、月 K 还会显示相对上一周期收盘价的涨幅
- 异动提示列仅标记今日发生异动的股票，提示颜色跟随今日最新异动方向；点击提示可在悬浮窗中查看最近 5 天的东方财富盘口异动详情
- 可手动将股票设为重点关注，持仓股票会自动加入重点关注且保持重点状态
- 在 Windows 11 任务栏直接显示多只股票的名称、实时价格和涨跌幅
- 可随时开启或关闭任务栏行情，重新开启时会自动恢复显示
- 可通过滑块自由调整任务栏行情的横向位置，避开已有任务栏内容
- 分别设置重点关注与其余股票的 3–300 秒刷新间隔，默认分别为 5 秒和 10 秒
- 重点、普通、指数和到期板块行情由主进程统一合并调度，避免多个刷新入口同时请求；板块报价固定缓存 60 秒
- 行情请求会记录调用来源、节点、耗时和返回数量，本地日志启动时自动清理超过 7 天的文件
- 支持开机自动启动、关闭窗口后驻留通知区
- 自选列表和设置保存在本机，不需要注册账号
- 支持将自选、持仓、排序、任务栏选择和应用设置导出为 JSON，也可从 JSON 配置完整恢复

## 安装与使用

1. 双击 `见涨-Setup-6.0.1-x64.exe`。如果已经安装旧版本，可选择原安装目录直接覆盖升级。
2. 选择安装目录并完成安装。
3. 在顶部搜索框输入 `600519` 或 `贵州茅台` 一类的代码/名称，选择结果后添加。
4. 点击“分红融资榜”可使用深度条件筛选、查看更新变化或在散点图中选股，并将股票加入自选。首次没有本地快照时软件会自动获取；数据超过 7 天只提示过期，由用户决定是否手动更新。
5. 点击股票行展开行情详情，默认显示分时走势，可按需切换五日、日 K、周 K、月 K、资金流向或所属板块指数；再次点击股票行可收起。
6. 在左侧“设置”列点击星标可切换重点关注；有持仓的股票会自动保持重点关注，并按重点股票的刷新间隔更新。
7. 在“设置”列点击任务栏图标，该股票的名称、实时价格和涨跌幅会直接显示在 Windows 11 任务栏空白区域；再次点击可取消。
8. 在“设置”列点击持仓图标，可录入持仓数量、成本价和是否本日建仓；首次保存持仓会按填写的数量、成本价和建仓日期自动生成一笔“底仓买入”交易记录。持仓快照下方显示最近 5 条统一交易记录，点击“查看更多”可在分页弹窗中查看全部记录。“本日建仓”会在次日自动失效，今日收益恢复按昨收计算。
9. 在“设置”列点击交易管理图标，可录入T仓买卖或底仓增减；全部流水会进入统一交易记录，当前T仓清空后填写券商最新持仓成本并确认结算即可归档本批次。打开活动批次后，可在“浮动盈亏提醒”中启用双向金额提醒，默认阈值为 ±100 元。
10. 在最左侧“排序”列拖动手柄可保存手动顺序，点击图钉可将股票置顶；点击任一数据列头可临时排序，点击“恢复手动排序”返回手动顺序。
11. 点击“调整列位置”，可将行情数据列向左或向右移动一格，也可直接移到最左或最右；弹窗内的列表会在下次打开时显示最新顺序，便于连续调整同一列。“排序”和“设置”固定在左侧，删除按钮位于不固定的末列。
12. 在“设置”中可分别修改重点关注和其余股票的刷新秒数，也可设置做T费用、任务栏行情、开机启动和关闭后驻留行为；“系统与数据”页可查看基本面快照状态并手动更新。
13. 在“设置”的“配置管理”中可导出或导入 JSON 配置；导入会先提示确认，确认后覆盖当前全部自选、持仓、做T账本和设置。

安装包未使用商业代码签名证书。Windows SmartScreen 可能显示“未知发布者”，请仅在确认安装包来自本交付目录时继续。

任务栏行情条使用透明、鼠标穿透窗口，不会拦截原任务栏的点击。使用任务栏自动隐藏时，行情条也会隐藏，避免覆盖其他应用内容。

## 数据说明

应用使用东方财富公开行情接口获取 A 股联想、批量报价、盘中分时、周期 K 线、盘口异动提示、个股资金流向和所属行业板块指数。行情存在网络延迟或服务调整风险，仅供信息参考，不构成投资建议。

基本面财务数据使用 schema v1，覆盖最近五个完整财年的加权/扣非加权 ROE、合并/归母/扣非归母净利润和经营现金流净额，以及最新完整财年的资产负债率、行业 P60 和公司行业百分位。当前版本只完成数据获取、规范化、缓存和软件读取接口，筛选及展示方式将在后续版本确定。

安装包不内置会过期的生产快照，只附带两个 Python 抓取脚本。首次启动发现某类快照不存在时会自动排队获取；分红融资榜超过 7 天、基本面快照超过 90 天或完整财年落后时，只在对应界面提示，不会自动刷新。运行脚本需要本机安装 Python 3 和 `requests`，环境缺失时软件会明确提示。

## 本地数据

自选股和设置保存在 Electron 的用户数据目录中，通常位于：

```text
%APPDATA%\jianzhang-stock-desktop\settings.json
```

行情请求日志位于同目录下的 `logs/market-requests-YYYY-MM-DD.jsonl`，仅保留最近 7 天。

分红融资榜位于同目录下的 `dividend-financing/`，其中包含当前/更新前快照、变化报告、Markdown 报告和诊断数据。软件启动时读取一次 schema v2 用户快照并在主进程和界面内存中复用；没有可用快照时自动运行附带脚本获取并保存到该目录。

基本面财务数据位于同目录下的 `fundamentals/`，包含 `snapshot.json` 和 `diagnostics.json`；没有可用快照时自动运行附带脚本获取并保存。两个脚本在源码开发时的默认输出仍是 `src/data/`，软件运行时会显式改为用户数据目录。

## 源码开发

需要 Node.js 20 或更高版本。

```powershell
npm install
npm run dev
npm run build
npm run package:win
```

技术栈：Electron、React、TypeScript、Vite、Lightweight Charts。
