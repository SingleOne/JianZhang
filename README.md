# 见涨

面向 Windows 11 的本地 A 股实时行情桌面应用。

## 功能

- 通过股票代码或中文名称搜索并添加自选股
- 批量刷新最新价、涨跌幅、今开、最高、最低和成交额
- 支持在独立排序列中拖拽或一键置顶股票、点击列头快捷排序，并可一键恢复手动顺序
- 支持自由调整行情数据列的位置；设置列固定在左侧第二列，四个快捷操作以两行图标展示，删除按钮独立放在表格末列
- 可录入持仓数量、成本价和是否本日建仓，实时计算持仓市值、今日收益、今日收益率、持仓收益和收益率
- 持仓天数按 A 股实际交易日计算，周末和交易所法定休市日不计入；程序每年首次运行时自动从上交所更新当年休市日历，也可在设置中手动刷新并查看最近刷新时间
- 新增独立做T账本，逐笔记录T仓买入、T仓卖出和增加底仓，自动维护当前T仓数量、移动加权成本、已实现收益与浮动收益
- 每个T批次提供默认 +1%、+2%、+3%、+4%、+5% 的五档卖出计划，可修改每档目标涨幅和卖出数量，并计算扣除预计费用后的本档及累计收益
- T仓清空后自动进入批次结算，可填写券商最新持仓数量和成本；填写后以持仓成本推算的做T收益为准，并保留流水收益用于对账
- 做T交易自动计算佣金、经手费、证管费、过户费和卖出印花税，支持在设置中调整费率，也允许逐笔覆盖实际费用
- 做T批次、全部交易流水、费用明细和最终收益永久保留在本地历史中，并随配置一并导入导出
- 在自选区域汇总展示全部持仓的今日总收益、今日收益率、持仓总收益和加权总收益率，收益卡片随正负显示红色或绿色阴影
- 在“添加自选”按钮后展示可自定义选择的大盘指数最新点位和涨跌幅，并以竖线分隔；指数卡片的边条和阴影随涨跌变为红色或绿色，支持上证、深证、创业板、沪深300、科创50、中证系列及北证50等常用指数
- 点击股票行展开最近交易日的盘中分时图；主接口失败时自动切换到 5 分钟备用数据
- 分时区域固定铺满展示 09:15 集合竞价至 15:00 收盘的完整时段，价格与成交量使用上下两个独立图表且不支持缩放，并标注连续竞价范围内的最高价和最低价
- 分时价格图通过背景区分集合竞价和连续竞价，保留本日成交均价线；鼠标移到价格或成交量数据点时，分别提示对应价格或成交量与成交额
- 展开区域提供分时、五日、日 K、周 K、月 K、资金流向和板块标签页，各类行情仅在首次打开对应标签时按需获取
- “板块”标签页展示股票所属主行业板块指数的最新点位、涨跌幅、今开、最高、最低、昨收、成交额和 09:30–15:00 连续竞价走势，价格轴根据实际波动自动缩放
- 五日图固定展示最近 5 个交易日的完整范围，不支持拖动或缩放
- 日 K、周 K、月 K 向外缩放时会自动补取更早行情，始终将最新交易日固定在图表最右侧，并标注当前可见范围内的最高价与最低价
- 鼠标移到五日或周期 K 线数据点时，今日概览会切换显示该点的开盘、收盘、最高、最低、成交量和成交额；日 K、周 K、月 K 还会显示相对上一周期收盘价的涨幅
- 异动提示列仅标记今日发生异动的股票，提示颜色跟随今日最新异动方向；点击提示可在悬浮窗中查看最近 5 天的东方财富盘口异动详情
- 可手动将股票设为重点关注，持仓股票会自动加入重点关注且保持重点状态
- 在 Windows 11 任务栏直接显示多只股票的名称、实时价格和涨跌幅
- 可随时开启或关闭任务栏行情，重新开启时会自动恢复显示
- 可通过滑块自由调整任务栏行情的横向位置，避开已有任务栏内容
- 分别设置重点关注与其余股票的 3–300 秒刷新间隔，默认分别为 5 秒和 10 秒
- 支持开机自动启动、关闭窗口后驻留通知区
- 自选列表和设置保存在本机，不需要注册账号
- 支持将自选、持仓、排序、任务栏选择和应用设置导出为 JSON，也可从 JSON 配置完整恢复

## 安装与使用

1. 双击 `见涨-Setup-3.0.2-x64.exe`。如果已经安装旧版本，可选择原安装目录直接覆盖升级。
2. 选择安装目录并完成安装。
3. 在顶部搜索框输入 `600519` 或 `贵州茅台` 一类的代码/名称，选择结果后添加。
4. 点击股票行展开行情详情，默认显示分时走势，可按需切换五日、日 K、周 K、月 K、资金流向或所属板块指数；再次点击股票行可收起。
5. 在左侧“设置”列点击星标可切换重点关注；有持仓的股票会自动保持重点关注，并按重点股票的刷新间隔更新。
6. 在“设置”列点击任务栏图标，该股票的名称、实时价格和涨跌幅会直接显示在 Windows 11 任务栏空白区域；再次点击可取消。
7. 在“设置”列点击持仓图标，可录入持仓数量、成本价和是否本日建仓；“本日建仓”会在次日自动失效，今日收益恢复按昨收计算。
8. 在“设置”列点击做T图标，可录入T仓买入、T仓卖出或增加底仓；当前T仓清空后，填写券商最新持仓成本并确认结算即可归档本批次。
9. 在最左侧“排序”列拖动手柄可保存手动顺序，点击图钉可将股票置顶；点击任一数据列头可临时排序，点击“恢复手动排序”返回手动顺序。
10. 点击“调整列位置”，可将行情数据列向左或向右移动一格，也可直接移到最左或最右；弹窗内的列表会在下次打开时显示最新顺序，便于连续调整同一列。“排序”和“设置”固定在左侧，删除按钮位于不固定的末列。
11. 在“设置”中可分别修改重点关注和其余股票的刷新秒数，也可设置做T费用、任务栏行情、开机启动和关闭后驻留行为。
12. 在“设置”的“配置管理”中可导出或导入 JSON 配置；导入会先提示确认，确认后覆盖当前全部自选、持仓、做T账本和设置。

安装包未使用商业代码签名证书。Windows SmartScreen 可能显示“未知发布者”，请仅在确认安装包来自本交付目录时继续。

任务栏行情条使用透明、鼠标穿透窗口，不会拦截原任务栏的点击。使用任务栏自动隐藏时，行情条也会隐藏，避免覆盖其他应用内容。

## 数据说明

应用使用东方财富公开行情接口获取 A 股联想、批量报价、盘中分时、周期 K 线、盘口异动提示、个股资金流向和所属行业板块指数。行情存在网络延迟或服务调整风险，仅供信息参考，不构成投资建议。

## 本地数据

自选股和设置保存在 Electron 的用户数据目录中，通常位于：

```text
%APPDATA%\见涨\settings.json
```

## 源码开发

需要 Node.js 20 或更高版本。

```powershell
npm install
npm run dev
npm run build
npm run package:win
```

技术栈：Electron、React、TypeScript、Vite、Lightweight Charts。
