# 见涨

面向 Windows 11 的本地 A 股实时行情桌面应用。

## 功能

- 通过股票代码或中文名称搜索并添加自选股
- 批量刷新最新价、涨跌幅、今开、最高、最低和成交额
- 支持拖拽调整自选股手动顺序、点击列头快捷排序，并可一键恢复手动顺序
- 支持自由调整表格列的位置
- 可录入持仓数量、成本价和是否本日建仓，实时计算持仓市值、今日收益、持仓收益和收益率
- 点击股票行展开最近交易日的盘中分时图；主接口失败时自动切换到 5 分钟备用数据
- 分时区域展示价格折线、本日成交均价线、成交量和今日概览
- 在 Windows 11 任务栏直接显示多只股票的名称、实时价格和涨跌幅
- 可随时开启或关闭任务栏行情，重新开启时会自动恢复显示
- 可通过滑块自由调整任务栏行情的横向位置，避开已有任务栏内容
- 自定义 3–300 秒刷新间隔
- 支持开机自动启动、关闭窗口后驻留通知区
- 自选列表和设置保存在本机，不需要注册账号

## 安装与使用

1. 双击 `见涨-Setup-1.0.4-x64.exe`。如果已经安装旧版本，可选择原安装目录直接覆盖升级。
2. 选择安装目录并完成安装。
3. 在顶部搜索框输入 `600519` 或 `贵州茅台` 一类的代码/名称，选择结果后添加。
4. 点击股票行展开 K 线；再次点击可收起。
5. 在“操作”列点击“任务栏”，该股票的名称、实时价格和涨跌幅会直接显示在 Windows 11 任务栏空白区域；再次点击可取消。
6. 在“操作”列点击“持仓”，可录入持仓数量、成本价和是否本日建仓；“本日建仓”会在次日自动失效，今日收益恢复按昨收计算。
7. 拖动股票名称左侧手柄可保存手动顺序；点击任一数据列头可临时排序，点击“恢复手动排序”返回手动顺序。
8. 点击“调整列位置”，使用左右箭头改变列的显示顺序。
9. 在“设置”中可开启或关闭“任务栏行情”；拖动“任务栏横向位置”滑块，可将行情移到任务栏空白处。这里也可修改刷新秒数、开机启动和关闭后驻留行为。

安装包未使用商业代码签名证书。Windows SmartScreen 可能显示“未知发布者”，请仅在确认安装包来自本交付目录时继续。

任务栏行情条使用透明、鼠标穿透窗口，不会拦截原任务栏的点击。使用任务栏自动隐藏时，行情条也会隐藏，避免覆盖其他应用内容。

## 数据说明

应用使用东方财富公开行情接口获取 A 股联想、批量报价和 5 分钟 K 线。行情存在网络延迟或服务调整风险，仅供信息参考，不构成投资建议。

## 本地数据

自选股和设置保存在 Electron 的用户数据目录中，通常位于：

```text
%APPDATA%\见涨\settings.json
```

## 源码开发

需要 Node.js 20 或更高版本。

```powershell
npm install
npm run dev
npm run build
npm run package:win
```

技术栈：Electron、React、TypeScript、Vite、Lightweight Charts。
